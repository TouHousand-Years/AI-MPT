# 定义试听任务生命周期与临时资源保留

Parent: ../map.md
Type: grilling
Status: open
Blocked by: 04, 05, 06

## Question

试听任务从校验、快照、渲染、人工发布、AI 请求、结果校验到完成/失败/取消应具有哪些状态与幂等规则；音频句柄、评审、调试日志和失败诊断在文档修改、关闭、应用退出、Sidecar 断连/重连与超时清扫时分别保留多久，并怎样遵守“除调试日志外不新增项目级持久化数据”？

## Completion evidence

- 产出状态机、状态转换表和资源保留矩阵，覆盖成功、并行人工/AI 分支、取消、超时、断连、重连、文档修改/关闭和应用退出。
- 明确任务请求幂等性、句柄授权、stale 转换、清扫触发与每类资源的所有者；除有界且脱敏的调试日志外不得产生项目级持久化数据。
- 为每个终态给出 typed failure 或完成包络，并说明迟到的提供商响应和人工提交如何处理。
- 与“决定项目级音频 Agent 提示词契约”核对任务创建时的创建触发、提示词读取时点和活动任务期间文件修改行为。
