## Question

## Completion evidence

- 产出 saved/unsaved/只读目录/已有文件/并发首次调用矩阵，决定规范路径、受信创建者、原子创建和不覆盖规则。
- 冻结系统提示词、主 Agent 提示词、项目 `AGENT.md` 与单次请求的合并顺序及版本/哈希记录。
- 明确主 Agent 写、音频子 Agent 只读的权限边界；未保存工程不得创建或改用全局文件，但必须继续工作并返回可见提示。
- 与试听任务生命周期核对创建触发、提示词读取时点和活动任务期间编辑行为，并给出可自动执行的文件系统测试表。
