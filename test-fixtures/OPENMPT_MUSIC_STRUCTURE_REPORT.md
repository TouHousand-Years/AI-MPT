# OpenMPT 当前工程乐曲结构与音源选择分析

初版日期：2026-09-14；分段和声与音色补充：2026-09-16

数据来源：OpenMPT Pattern MCP 的 Sequence order 与重新读取的 49 个 Pattern 的 Score Context（纯数据分析，未试听）。下文 Order、Pattern、Channel、行号均从 0 开始，行号使用十进制；Instrument 编号沿用工程的 1 起始编号。

## 1. 工程概览

- 格式：MPTM
- Sequence：0，共 46 个 Order，全部为 Pattern，无 skip / stop 标记
- Pattern：正式 Sequence 使用 46 个；Pattern 42、43、44 未引用且为空
- 每个 Pattern：128 行；8 行/拍，32 行/小节，即每个 Pattern 4 小节
- 默认速度：Speed 6，Tempo 158 BPM，现代 Tempo Mode（`tempo_mode: 2`）
- 通道数：11
- 按默认速度估算，46 个 Order 约为 184 小节、4 分 39 秒；实际时长可能受 Pattern 内效果命令影响

## 2. 总体曲式

Sequence 的 Pattern 顺序为：

`0–36 → 38 → 39 → 47 → 48 → 40 → 41 → 45 → 46 → 37`

可按配器、密度和音色组切换划分为：

| 段落 | Order / Pattern | 约略功能 | 配器和能量特征 |
|---|---|---|---|
| A0 引子 | O00 / P0 | 主题材料展示 | 70 个音符事件；长时值方波和声、少量鼓点，空间很大 |
| A1 展开 | O01–O02 / P1–P2 | 由静态和弦进入快速运动 | P1 密度骤升至 480；P2 回落至 271，像收束或连接 |
| B Bass 主导段 | O03–O10 / P3–P10 | 第一轮主体/推进 | `acousticbass`、`EBass3`、`desirebass` 依次成为核心，鼓组持续完整；密度约 332–532 |
| Break 1 | O11 / P11 | 明确断点 | 仅 6 个打击触发，旋律与和声声部全部退出 |
| C 新音色组进入 | O12–O15 / P12–P15 | B 前半材料移调后的新章节 | P12–13 使用第二套乐器编号 17–20；P14–15 前景换回 6，恢复到 532–546 的高密度 |
| D 主体扩展 | O16–O23 / P16–P23 | 长篇稳定高潮 | 方波/脉冲型声部持续十六分运动，Bass 与鼓组稳定；多数 Pattern 约 480–550 个事件 |
| Coda/过渡 | O24 / P24 | 材料拼接、降密度 | 215 个事件，前后两套音色交接，鼓层明显减少 |
| Break 2 | O25 / P25 | 第二个明确断点 | 与 P11 同型，仅 6 个打击触发 |
| A' 移调再现 | O26–O28 / P26–P28 | 引子与展开的移调/变体 | P26 与 P0 结构高度相似但整体低约半音；P27–P28 对应 P1–P2 的简化再现 |
| B' 再现 | O29–O36 / P29–P36 | Bass 主导段回归 | 与 P7–P10 同类，中心音高和打击密度有变化；后半鼓层更厚 |
| E 终章高潮 | O37–O44 / P38,P39,P47,P48,P40,P41,P45,P46 | 全编制高潮与重复强化 | 每 Pattern 561–630 个事件；方波和声、Bass、鼓组几乎全程满载；P47≈P38，P45=P40，形成重复推进 |
| 尾声 | O45 / P37 | 回到开头材料并保留节奏 | 226 个事件；重现 P0 的和声轮廓，但加入连续镲/节奏层，像回环式结束 |

整体可概括为：**引子—第一主体—断点—第二主体/长展开—断点—移调再现—终章高潮—回环尾声**。两个极稀疏 Pattern（P11、P25）把全曲切成三个大区块；最后九个 Order 则通过重复 Pattern 和加厚打击乐形成最大能量峰值。

## 3. 通道与声部分工

通道没有文字名称，以下角色由音域、乐器编号、触发密度和重复关系推断：

| 通道 | 主要角色 | 证据 |
|---|---|---|
| Ch 0、Ch 2 | 双线条旋律/高音 Bass 装饰或呼应声部 | 经常成对使用同一 Instrument 与近似音域；在 Bass 主导段使用 `acousticbass`，后段改用 `f7c` 命名的 Instrument |
| Ch 1 | 核心持续运动声部，常兼具 Bass ostinato 或内声部功能 | 多数主体 Pattern 固定 64 次触发，即每两行一次；先后使用 `EBass3`、`f3c` 等 |
| Ch 3、Ch 4 | 和声主体/双声部琶音 | 常成对构成不同音高层，使用 `f7c` 或同类方波音色；每 Pattern 可达 64+64 次触发 |
| Ch 5、Ch 6 | Ch 3/4 的高八度或强化层 | 音高轮廓高度对应 Ch 3/4，但常高约一个八度；部分段落使用名为 `drums` 的 Instrument，实际按有音高材料写作，可能是特殊合成/映射而非传统鼓组 |
| Ch 7 | 军鼓、休止占位及节奏填充 | 主要使用 `Snarepop`、`rest`，后半使用第二套对应编号 23/26/29 |
| Ch 8 | 顶镲/附加军鼓 | 主要使用 `2608_TOP` 或 Snare 类样本；终章触发密度增至每两行甚至更密 |
| Ch 9 | 固定脉冲/打击层 | `p7`，常为 64 次等间距触发；音符恒为 C-5，表明音高只是样本触发键 |
| Ch 10 | 高频节拍层 | `2608_HH`，常为 64 次触发，承担稳定 hi-hat 网格 |

## 4. Bass 选择

工程没有只用一种 Bass，而是用三种命名明确的 Bass 做段落区分：

1. `acousticbass`（Instrument 6）
   - 常见于 Ch 0/2，采用成对、较疏的旋律化写法。
   - 在 P3–P10、P29–P36 中反复出现，音域有时很高，说明它不只承担根音，也用于有拨弦感的旋律性填充。
   - 可确认的作用：用 Bass 命名的音色演奏高音旋律及延迟呼应。名称暗示原声 Bass，但是否具有真实拨弦瞬态，尚未试听确认。

2. `EBass3`（Instrument 7；后半对应 Instrument 19）
   - 主要集中在 Ch 1，典型写法为每两行一次、每 Pattern 64 个音符的连续 ostinato。
   - 作用：承担最稳定的低音驱动力和节奏骨架，是第一主体及第二主题的重要地基。

3. `desirebass`（Instrument 9）
   - 主要用于 P7–P10 与其再现 P29–P36，分布在 Ch 3/4；常与 Ch 5/6 的高八度强化层平行。
   - 可确认的作用：承担主题性双声部与宽音域装饰。它与 `EBass3` 的实际明暗、瞬态和合成质感差异，尚未试听确认。

评价：三种 Bass 的分工有清楚的章节辨识度；但 `acousticbass` 被写到很高音区，而 `desirebass` 又与和声声部共用 Ch 3/4，因此“Bass、内声部、主旋律”的边界是流动的。这是偏芯片/Tracker 编曲的长处，但如果目标是现代混音，可重点检查低频是否在 Ch 1 与 Ch 3/4 间发生掩蔽。

## 5. 和弦与伴奏音色

- 样本名称大量出现 `1:1 Square`、`square`，支持工程具有方波类音源线索；实际使用的 Instrument 名包括 `f3c`、`f7c`、`f8d`、`s1h` 等。当前接口没有返回 Instrument 的键盘映射、插件路由与音色参数，不能把同编号 Sample 当作其确定音源，也不能仅凭名称断定每个 Instrument 的波形。
- P0 的 Ch 0/1 与 Ch 3/4 以稀疏、长时值双音构造和声骨架；Ch 5/6 再作高音强化。
- P1 之后，Ch 3–6 大量采用每两行触发并配合 note-off 的短音型，和弦从“铺底”转为快速分解或切分型织体。
- 后半使用第二组乐器编号 16–22、28、30；同名 `f7c` 有多个实例。它们是否仅改变包络、音区或音量，无法从当前数据确认；尤其 Instrument 28 只名为 `untitled`。
- 多个声部采用八度复制，在终章 Ch 3–6 全部达到每 Pattern 64 次触发。叠层的实际厚度与中高频是否拥挤，需要结合音色参数和试听判断。

## 6. 主旋律判断

没有单一通道从头到尾独占主旋律。更合理的解释是“旋律角色在声部间交接”：

- 引子/再现：Ch 0/1 与 Ch 3/4 的长音上行轮廓共同构成主题，而 Ch 2 提供少量高音提示。
- 第一 Bass 主导段：Ch 0/2 的 `acousticbass` 成对乐句最像前景旋律；Ch 1 的密集线条更像持续运动的骨架。
- `desirebass` 段：Ch 3/4 的宽音域线条具有主题性，Ch 5/6 同步强化，形成“Bass 音色承担旋律”的效果。
- D、E 段：Ch 0/2 使用 `f7c` 命名的 Instrument 接管前景，Ch 1 和 Ch 3–6 维持稳定 ostinato 与和声网格。

这类写法强调复调和音色层，而不是传统“伴奏 + 单旋律”的严格分层。

## 7. 鼓组与节奏音源

- `Snarepop`：主要在 Ch 7，担当清晰军鼓重音。
- `2608_TOP`：主要在 Ch 8，提供顶部镲片/明亮瞬态。
- `p7`：主要在 Ch 9，持续固定触发，可能是底鼓、脉冲打击或特定芯片鼓音；仅凭 Pattern 数据无法可靠确认听感。
- `2608_HH`：主要在 Ch 10，承担连续 hi-hat 网格。
- `rest`：并非普通空白，而是作为 Instrument 事件写入；应理解为编曲/触发控制的一部分。
- P11、P25 只剩少量 Ch 7/9/10 事件，是结构性的停顿标记。
- 终章 P40/P41/P45/P46 显著加厚 Ch 8；P46 达到全曲最高约 630 个音符事件，最后 32 行的密度尤其高，承担终章冲顶。

## 8. A–E 分段和弦与主要音色

### 8.1 判读方法与总览

这里的“常用和弦”指本曲各段反复出现的和声骨架，不是为该风格推荐的通用和弦。先根据持续音、反复音型及旋律落点找出和声，再合并同一和声区间内的分解音；没有把整段所有音级合成一个巨大的和弦，也没有把每次旋律经过音都算成换和弦。

- **名称与音高证据分开。** 完整三和弦、七和弦可明确命名；只有根音和五度时写作 `5`，缺少三音时不强判大小调。`m` 为小和弦，`maj7` 为大七和弦，`7` 为属七和弦，`dim` 为减三和弦。
- **斜线表示编曲上的低音支点。** 例如 `Cm7/B♭` 表示 C 小和弦材料叠加 B♭ 的低音型。Ch 1 的“Bass”是功能角色，Ch 3/4 有时反而写得更低，因此这些符号是和声缩减，不保证每个瞬间的实际最低音等于斜线后的音。
- **同音异名按和声拼写。** Tracker 的 `G` 在 D# 大和弦中应读为 F𝄪；`F` 在 C# 大和弦中应读为 E#。C 小调中的 `D# / G# / A#` 则记为 E♭ / A♭ / B♭。下文必要时同时标出屏幕音名，便于核对。
- **节奏层不参与定和弦。** Ch 7–10 的固定触发键排除；Ch 5/6 常复制 Ch 3/4，也不重复计为新的和声音级。和弦依据主要来自 Ch 0–4 的记谱音高，尚未模拟滑音、包络尾音或插件移调。
- **“主要音色”依据分工与使用位置。** 不是按事件最多就判为主旋律，也不把同名 Instrument 自动视为同一音色设置。

| 段落 | 主要和声材料（缩减） | 主要音色与角色 |
|---|---|---|
| A：P0–P2 | 引子 `C#m → D# → E → F#`；展开保留支点并加入 G# 小调音型 | 1 `f3c` 和声支点；2 `f1t` 固定音型；3 `2ra` → 5 `f7c` 上方声部；4 `drums` 复制强化 |
| B：P3–P10 | 前半 `G#m → B/F# → C#/E# → E → F#`，密集版加入七音；后半 `G → A#dim → Bm` | 6 `acousticbass` 前景；7 `EBass3` → 1 `f3c` 持续音型；8 `f7c` → 9 `desirebass` 双声部 |
| C：P12–P15 | B 前半上移大三度：`Cm → E♭/B♭ → F/A → A♭ → B♭`，密集版含 F7/A 等色彩 | 17 `f8d` → 6 `acousticbass` 前景；19 `EBass3`；20 `f7c` 与 18 `s1h` 伴奏 |
| D：P16–P23 | `Cm → Cm7/B♭ → A♭maj7 → G7`，末格交替保留 `Cm/G`；后半升半音 | 21 `f7c` 旋律/呼应；16 `f3c` 持续音型；22 `f7c` 和声；28 `untitled` 高八度层 |
| E：O37–O44 | `F#m → F#m7/E → Dmaj7 → C#7`；后半升半音至 G 小调，末格同样交替保留主和弦材料 | 延续 D 配器；后半 Ch 2 换 30 `f7c` 与旋律同步；镲片显著加密 |

上述每行是材料总览；具体省略音、末格变化与换段例外如下。

### 8.2 A：引子与展开（O00–O02 / P0–P2）

**常用和弦。** P0 最清楚地展示 `C#m → D# → E → F#`，每 64 行重复一次。若结合随后 B 前半的 G# 小调中心，可理解为 `iv → V → VI → VII` 的铺垫，而非仅凭起始和弦就判定整曲为 C# 小调。

| P0 行号 | Ch 0/1 的支点 | Ch 3/4 的上方音 | 和弦判读 |
|---|---|---|---|
| 0、64 | C#、G# | G#、E | C#m；第二轮 Ch 2 的 D# 为附加色彩 |
| 16、80 | D#、A# | A#、G（F𝄪） | D# 大三和弦，含 G# 小调的升导音 |
| 28、92 | E、B | B、G# | E 大三和弦 |
| 48、112 | F#、C# | C#、A# | F# 大三和弦 |

换和弦位置为 `0 → 16 → 28 → 48 → 64`，并非每小节一次；28 行处提前进入 E。P0 的 123 行起有上滑效果，所以表内最后一格描述的是记谱起始和声，不代表滑音后的精确音高。

P1/P2 的 Ch 0/1 延续这组根音—五度支点，但 Ch 3/4 改为快速双线条。P1 开头一格的音级以 C#、G#、B、D#、A# 为主，**没有 P0 的 E 三音**，更适合记为 `G#m/C#` 或 C# 上的悬挂/扩展织体，不能逐格照抄 P0 的完整三和弦。D# 支点处出现 G（F𝄪）、A#、C#，加强 D#7 色彩；E 支点上方出现 D#，形成 Emaj7 色彩。F# 格则带有六度、九度及经过音。P2 的 112、120 行转为 E/B、F#/C# 的短连接，准备进入 B。

**主要音色。** P0 的 Ch 0/1 使用 1 `f3c`，Ch 3/4 使用 3 `2ra`，Ch 5/6 的 4 `drums` 与上方双音同音复制。P1 起 Ch 3/4 换成 5 `f7c`，4 则主要作高八度复制。Ch 2 的 2 `f1t` 在 P1 每两行触发，反复奏出 D#–G#–B–A#，是独立的固定音型。P2 末尾 Ch 0/1 短暂换入 6 `acousticbass`，是音色上的接段提示。

A 的辨识点是“长时值三和弦支点转为高速双线条”，并非三种 Bass 同时主导。节奏层从 P0 的少量 10 `Snarepop`、11 `2608_TOP`，转为 P1 的 12 `p7`、14 `2608_HH` 连续网格。

### 8.3 B：两个不同的 Bass 主导乐句（O03–O10 / P3–P10）

**B 前半，P3–P6：G# 小调材料与半音下降低音。** 常见低音支点为 `G# → F# → E# → E → F#`。下表以 P3 为稀疏版本、P5 为密集版本；“低音”取 Ch 1 的持续音型支点，并用 Ch 3/4 及旋律补足和弦。

| Pattern 内行段 | 直接音高依据 | 和声缩减与限制 |
|---|---|---|
| 0–31 | 伴奏 G#、D#；旋律以 B 开始 | G#m；P5 琶音进一步明确 B、G#、D# |
| 32–63 | 伴奏 F#、D#；旋律落在 B | B/F#；密集版另有 A#、G#、C#，带大七、六度、九度色彩 |
| 64–95 | 伴奏 E#（显示 F）、C#，旋律补 G# | C#/E#；P5/P6 加入 B，形成 C#7/E# 的骨架 |
| 96–111 | E、B 支点，旋律/琶音出现 G#、D# | E，常带 Emaj7 色彩 |
| 112–127 | P3–P5 使用 F#、C# 支点 | 稀疏版为 F#5 加旋律；P5 上方保留 G#、B、D#，可缩减为 G#m7/F#，不宜只写干净的 F# 大三和弦 |

其中 `C#7/E#` 是突出色彩：在 G# 小调语境中相当于大 IV/IV7 色彩，E# 让低音经 F#–E#–E 形成半音连接。P6 的末 16 行已改变 Bass 与声部材料，为 P7 接段，不按上表最后一格机械循环。

**B 后半，P7–P10：B 小调材料。** 反复出现 `G → A#dim → Bm`；以 B 小调为中心，可读作 `VI → vii° → i`。

- P7 行 0 的 Ch 3/4 为 G、B；Ch 1 随后补 D，明确 G 大三和弦。
- 行 16 的 Ch 3/4 为 A#、C#，Ch 1 的持续音型补 E，得到 A#–C#–E。这里是 **A#dim**，不是 A# 大和弦；它也具有省略根音 F#7 的属功能暗示，但 F#7 不是这一格最直接的记谱名称。
- 行 32 的 B、D 与 Ch 1 的 F# 明确 Bm；后续快速装饰围绕 B、D、F# 展开。
- Ch 1 在 56–63、120–127 行短暂转到 A–E；上方仍有 Bm 的音，可作 Bm7/A 的连接理解。各 Pattern 上方有变奏，因此这是短暂连接色彩，不另立为全段主和弦。

这组三格骨架每 64 行出现一次，P7–P10 共八轮主题陈述，后几轮增加了内声部活动。

**主要音色。** P3–P6 的前景是 Ch 0/2 的 6 `acousticbass`，Ch 2 常晚 6 行进入，形成写在谱面上的呼应；Ch 1 使用 7 `EBass3`，Ch 3/4 使用 8 `f7c`。P7–P10 保留前景 6，却把 Ch 1 换为 1 `f3c`，Ch 3/4 换为 9 `desirebass`：因此后半持续 Bass 已不再主要使用 `EBass3`。4 `drums` 继续复制双声部，节奏以 10/11/12/14 为主。

### 8.4 C：B 前半材料上移大三度（O12–O15 / P12–P15）

**常用和弦。** 这里与 P3–P6 的联系很强：P12 的伴奏支点、P14 的琶音骨架，是相应 B 前半材料上移 4 个半音后的版本，旋律另有八度配置变化。因此 C 更准确的描述是“旧主题移调并重新配器”，而不是已证实的全新主题。

| 行段 | P12/P13 的稀疏骨架 | P14/P15 的密集版本 |
|---|---|---|
| 0–31 | C、G，加旋律 E♭：Cm | Ch 3/4 明确 C–E♭–G，另有 D、F 装饰 |
| 32–63 | B♭、G，加旋律 E♭：E♭/B♭ | 上方出现 C、D、F 等，含 E♭maj7/B♭、Cm7/B♭ 的重叠色彩 |
| 64–95 | A、F，旋律补 C：F/A | 琶音加入 E♭，明确 F7/A 骨架；G、D 提供九度、十三度色彩 |
| 96–111 | A♭、E♭，旋律补 C、G：A♭maj7 色彩 | 保留 C 小调琶音，A♭maj7 骨架更清楚 |
| 112–127 | B♭、F 支点加活动旋律 | 上方继续 C–E♭–G，可缩减为 Cm7/B♭，并非每次都落成 B♭ 大三和弦 |

本段最有辨识度的是 `C → B♭ → A → A♭ → B♭` 的低音轮廓，以及 C 小调中出现 F 大和弦/F7 的 A 自然音。P12–P15 四次陈述同一低音框架，后两次把稀疏双音改为十六分音型。

**主要音色。** P12/P13 的 Ch 0/2 使用 17 `f8d`；P14/P15 换回 6 `acousticbass`，所以 C 并非全段都由第二套编号担任旋律。Ch 1 始终使用 19 `EBass3`，Ch 3/4 使用 20 `f7c`，Ch 5/6 使用 18 `s1h`，后两组在这段是同音复制，不能一概称为高八度层。P12/P13 节奏稀疏；P14/P15 才全面换入 23 `Snarepop`、24 `2608_TOP`、25 `p7`、27 `2608_HH`。

### 8.5 D：小调音型叠加下降低音（O16–O23 / P16–P23）

**常用和弦。** P16–P19 围绕 C 小调展开，P20 从行 16 起把相同结构升高半音至 C# 小调，延续到 P23。它的关键是：低音支点下降时，上方小调音型大部分保持不变。

| 主要行段 | P16–P19：C 小调 | P20–P23：C# 小调 | 依据 |
|---|---|---|---|
| 16–47 | Cm | C#m | Ch 1 支点 C / C#；Ch 3/4 循环主和弦材料并插入二、四级音 |
| 48–79 | Cm7/B♭ | C#m7/B | Ch 1 降至 B♭ / B，上方仍是 Cm / C#m 材料 |
| 80–111 | A♭maj7 | Amaj7 | 支点 A♭ / A 与上方 C–E♭–G / C#–E–G# 合成大七骨架 |
| 112–127 及下一 P 的 0–15 | G7 或 Cm/G | G#7 或 C#m/G# | 奇偶乐句交替改变上方三音，详见下文 |

P16 的前 16 行没有新的有音高触发；P17–P19 的前 16 行延续前句末格。P20 前 16 行还保留 C 小调材料，**移调点在 P20 行 16**，不是 Pattern 起点。

末格分两类，不能全部统一写成 V7：

- P16/P18 行 112 起及其后 P17/P19 行 0–15，上方出现 B 自然音，与 G、D、F 构成 G7；E♭、C 是伴随的色彩/经过音。P20/P22 对应位置升为 G#7，其中大三音 B# 在 Tracker 显示为 C。
- P17/P19 行 112 起则保留 C、E♭、G 的小调材料，Ch 1 仍在 G，较合适的缩减为 Cm/G，伴随 D、F。P21/P23 对应位置为 C#m/G#。这是属低音上的主和弦延留，并没有写出同样明确的大三音。

因此其常见模型是“主小和弦 → 加降七级低音 → VI 大七 → 属七/主和弦延留”的交替，而非四个无差别的大、小三和弦。

**主要音色。** Ch 0/2 的 21 `f7c` 承担前景与晚 4 行的呼应；Ch 1 使用 16 `f3c`，Ch 3/4 使用 22 `f7c`，Ch 5/6 用 28 `untitled` 高一个八度复制。16、21、22、28 在此是稳定的四层分工。P21 的鼓层明显收缩，仅见 `rest` 类事件和部分 27 `2608_HH`，说明 D 内部也有减法编配，不能理解为全程相同厚度。

### 8.6 E：D 的材料升区再现与半音抬升（O37–O44）

**常用和弦。** E 的正确播放顺序是 `P38 → P39 → P47 → P48 → P40 → P41 → P45 → P46`。前四个 Pattern 以 F# 小调材料为中心，后四个升高半音至 G 小调；不能按 Pattern 数字顺序分析。

| 行段 | 前半：P38/P39/P47/P48 | 后半：P40/P41/P45/P46 |
|---|---|---|
| 0–31 | F#m：F#–A–C# | Gm：G–B♭–D |
| 32–63 | F#m7/E：上方 F#m，Ch 1 支点 E | Gm7/F：上方 Gm，Ch 1 支点 F |
| 64–95 | Dmaj7：D–F#–A–C# | E♭maj7：E♭–G–B♭–D |
| 96–127，第一类 | P38/P47：C#7，含 E#（显示 F）、G#、B | P40/P45：D7，含 F#、A、C |
| 96–127，第二类 | P39/P48：F#m/C#，上方保留 F#–A–C# | P41/P46：Gm/D，上方保留 G–B♭–D |

每个 Pattern 恰好一轮四格，每格 32 行；全段共八轮，两个调性区各四轮。与 D 相比，和声起点由行 16 移到行 0，四格轮廓更整齐。前半第二格也能听作 E 上的扩展和声，但用 `F#m7/E` 更能反映上方音型没有整体改写的事实；G#、B 等活动音仍应保留为旋律/扩展色彩，而非删除。

**主要音色。** Ch 1/3/4/5/6 延续 D 的 16 `f3c`、22 `f7c`、28 `untitled`。前半 Ch 0/2 都用 21 `f7c`，保留 4 行错位。后半 Ch 0 仍为 21，Ch 2 改为 30 `f7c`，音符转为同时间、同音高的同步叠层。这是终章加厚的重要写谱变化；仅凭同名无法断定 21 与 30 的音色参数相同。

鼓层上，前半 Ch 8 多用 11 `2608_TOP`，P48 尾部转入 24；后半 Ch 8 使用 24 `2608_TOP`，四个 Pattern 的有音高触发数由前半的 140 次增加为 272 次（此处只计触发事件，不等同实际响度）。25 `p7` 与 27 `2608_HH` 则各保持每 Pattern 64 次触发。E 的高潮来自**音高抬升、和声音型重复、旋律同步叠层与镲片加密**的共同作用。

### 8.7 A′、B′、过渡与尾声

| 段落 | 和弦与移调变化 | 音色变化 |
|---|---|---|
| A′：P26–P28 | P26 的完整三和弦为 `Cm → D → E♭ → F`，比 P0 精确低半音；P27/P28 对应的快速音型同样下降，P28 尾部另作连接 | 仍用 1/2/3/5/4 的引子层次，打击更稀疏；P28 末尾接入 6 |
| B′ 前半：P29–P32 | P7–P10 材料低半音：`G♭ → Adim → B♭m`，短连接可见 B♭m7/A♭；Tracker 分别显示 F#、A/C/D#、A#/C#/F | 6 `acousticbass` + 1 `f3c` + 9 `desirebass` + 4 `drums`，并未回到 B 前半的 7 `EBass3` |
| B′ 后半：P33–P36 | 同一模型移至 D 小调：`B♭ → C#dim → Dm`，短连接含 Dm7/C；相对 P29–P32 上移大三度 | 保留同一有音高编制，主要加厚打击层 |
| P24 过渡 | 行 16 起重新出现 B 前半的 G#–F#–E#–E 低音轮廓，前 16 行承接 C#m/G#；不作为独立新主题 | 行 16 起，21/16/22/28 分别换为 17/19/20/18，形成成组换色 |
| P11、P25 断点 | 没有新的 Ch 0–6 有音高触发，不另指定新和弦；此前尾音是否仍可听见待试听 | 只保留少量节奏/控制事件 |
| P37 尾声（O45） | 回到 P0 的 `C#m → D# → E → F#` 原音高框架，而不是继续 A′ 的低半音版本 | 恢复 1/2/3/4 的引子组合，并保留连续节奏层 |

**对原调性概述的修正：** 全曲不能用单一“C# 小调/E 大调”概括。更有证据的分段中心是：A 为 G# 小调语境作铺垫；B 从 G# 小调材料转向 B 小调；C 为 C 小调材料；D 从 C 小调升至 C# 小调；B′ 经 B♭ 小调、D 小调材料；E 从 F# 小调升至 G 小调。这里的“中心”是依据持续音型、三音、导音与主题重现作出的分析，并不表示各段只使用一种七声音阶。

## 9. 音源选择评价与建议

优点：

- 方波家族统一了整体审美，三个 Bass 音色则有效区分章节。
- 打击乐四层分工清楚，能用密度变化直接塑造段落能量。
- 第二套 Instrument 编号保持相似音色语汇，同时允许包络或层次变化，适合长篇 Tracker 乐曲。
- 引子、主体、断点、再现和终章之间的编配反差明确。

建议后续人工试听重点：

1. 检查 `acousticbass` 高音旋律是否过薄、过尖，是否需要与真正低频 Bass 分离。
2. 检查 Ch 3–6 的四层方波在终章是否产生中高频拥挤或相位感过强。
3. 确认 Instrument 4 `drums` 在 Ch 5/6 的有音高写法实际听感；它可能是命名误导或特殊映射。
4. 确认 `p7` 的真实打击类型，以便准确描述 Ch 9 是底鼓、脉冲鼓还是其他节奏层。
5. 试听 P11、P25 的停顿长度，以及 P46 到 P37 的高潮—尾声衔接是否自然。

## 10. 分析边界

本报告基于 Pattern 事件、音域、乐器/样本名称、密度和 Sequence 顺序分析，没有通过 UI 自动化或音频回放检验。此次通过 MCP 切换并读取 49 个既有 Pattern，未修改乐曲数据；只读会话已由 `release_occupancy` 成功释放。视觉与 UI 检验仍依仓库约定由人工完成。

分段和弦是记谱音高的和声缩减，不是实际音频的逐帧转录；“主旋律角色”“调性中心”与功能解释属于分析判断。Instrument 编号、名称、使用通道、触发位置与移调关系可由数据直接核对；实际音色质感、插件映射、声部响度，以及 `p7`/`drums`/`untitled` 的声学身份仍待人工试听确认。

此次核对包括：P0/P26 的 Ch 0/1/3/4 整体低半音；P3/P12、P5/P14 的 Ch 1/3/4 整体高大三度；P7/P29 的 Ch 0–6 整体低半音；P29/P33 的 Ch 0–6 整体高大三度；P38/P40 的 Ch 0/1/3/4/5/6 整体高半音。这些比较均核对了音符数量、行位置与音高差，另抽查了第 8 节关键三和弦、七和弦的构成音；没有以音符集合匹配代替人工听感验证。
