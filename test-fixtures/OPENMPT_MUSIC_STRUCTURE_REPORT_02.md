# OpenMPT 第二工程乐曲结构与音源选择分析

分析日期：2026-09-16

数据来源：当前连接工程的 Sequence 0，以及 P0–P23 共 24 个 Pattern 的完整 Score Context。采用与[前一份报告](OPENMPT_MUSIC_STRUCTURE_REPORT.md)相同的曲式、声部分工、Bass、和声、旋律、节奏与逐段分析框架。

本次工程特征为 **IT、9 通道、24 个 Order、首项 P23**。接口未提供工程文件名或曲名，因此以“第二工程”标识，避免把本地其他文件名误认成当前文档。Order、Pattern、Channel 与行号均从 0 开始，行号使用十进制；Instrument 编号从 1 开始。下文音高为 Tracker 记谱音高，不直接等于采样或插件最终发声的绝对音高。

## 1. 工程概览与实际播放路径

| 项目 | 读取结果 |
|---|---|
| 格式 | IT，传统 Tempo Mode（`tempo_mode: 0`） |
| Sequence | 0，名称为空 |
| Order | 24 个，均引用有效 Pattern；没有 skip/stop 条目 |
| 存在的 Pattern | P0–P23，全部被曲序引用，没有未引用 Pattern |
| 通道 | 9 个，Ch 0–8 |
| Pattern 长度 | 每个 128 行 |
| 默认时间设置 | Speed 2，Tempo 240；网格标记为 4 行/拍、16 行/小节 |
| 实际开头速度命令 | P23 行 0 与 P0 行 0 均设置 Tempo 146（T92）；全曲未发现 Speed 改写 |
| 乐器/样本表 | 16 个 Instrument 条目、31 个 Sample 条目，其中多个 Sample 为零帧空槽 |

曲序表面上的顺序是：

`O00:P23 → O01:P0 → … → O21:P20 → O22:P21 → O23:P22`

但实际播放必须计入两个效果命令：

| 位置 | 命令 | 对曲式的影响 |
|---|---|---|
| P23 行 12，Ch 0 | Pattern Break，参数 0（C00） | 播放完这一行后，进入下一 Order 的 P0 行 0；P23 不会完整播放 128 行 |
| P20 行 127，Ch 7 | Position Jump，参数 0（B00） | 跳回 Order 0，也就是 P23，而非直接进入 P21 |

因此，从曲首遵循这些命令播放，主路径为：

**短打击引入 P23 → P0–P20 → 返回 P23。**

P21/P22 虽然存在、被曲序引用且有内容，却不在这一自然播放路径上。不能把它们计入已播放的尾声，也不能称为“未引用 Pattern”。它们的用途需由作者确认，本文只分析其现有材料。

### 时间与小节口径

本曲大量音符以 **3 行**为间隔，和声/琶音材料以 **48 行**为主要单位；三个 128 行 Pattern 合计 384 行，正好容纳八个 48 行单位。128 不能被 48 整除，所以同一乐句起点会在相邻 Pattern 中依次落到行 0、16、32 等位置。Pattern 边界不等于乐句或小节边界。

为便于音乐分析，本文把 48 行视为一个推定的 4/4 小节：每拍 12 行、每个三行触发为十六分音符。这个口径符合音型和和声重复关系，属于分析用拍组，**区别于工程保存的 16 行/小节网格标记**。

传统模式每 tick 约为 `2.5 / Tempo` 秒。按 Speed 2、Tempo 146，且不计外部播放速度调整与采样取整：

- 每行约 `2 × 2.5 / 146 = 0.03425` 秒。
- P23 实际播放行 0–12，共 13 行，约 0.445 秒。
- P0–P20 合计 2688 行，即 56 个推定小节，约 92.05 秒。
- 从 P23 开始到第一次跳回它，约 **92.50 秒（1 分 32.5 秒）**，不是整曲自然结束时间。

计时公式已对照本仓库 `openmpt-original_ref/soundlib/Sndfile.cpp` 的 `RecalculateSamplesPerTick` / `GetTickDuration`；这仍是数据估算，未实际回放计时。

## 2. 总体曲式

A–E 是本报告为说明结构而设的分析标签，不是工程中已有的 Pattern 名称。E 是 D 的再现与节奏变体，不是另一个独立的新主题。

| 段落 | Order / Pattern | 推定长度 | 功能与配器特征 |
|---|---|---|---|
| 引入 | O00 / P23 行 0–12 | 13 行 | Ch 0–6 先切音，Ch 7/8 三组固定键触发，随后跳入正文 |
| A 固定音型引子 | O01–O03 / P0–P2 | 8 小节 | D# 小调支点；长五度、反复 Bass 与连续琶音逐渐叠入；每 Pattern 210–243 次音符触发 |
| B 旋律进入 | O04–O09 / P3–P8 | 16 小节 | 下降 Bass 加上 Ch 1/2 的旋律与延迟呼应；前后三个 Pattern 共用伴奏而改变旋律；249–258 次触发 |
| C 短句与大小调色彩转换 | O10–O15 / P9–P14 | 16 小节 | 旋律变为短促的八度/和声提示；伴奏在六行、三行间切换，强化层逐步降低八度；184–221 次触发 |
| D 新调性与换色 | O16–O18 / P15–P17 | 8 小节 | 转入 A# 小调材料；Bass ostinato 退出，低位长五度支撑多八度琶音；217–225 次触发 |
| E D 段再现 | O19–O21 / P18–P20 | 8 小节 | Ch 0–6 的音符位置与音高逐一重复 D；主要改写打击层，末尾跳回引入；226–230 次触发 |
| 主路径之外的材料 | O22–O23 / P21–P22 | 存储长度 256 行 | 重现 D# 小调引子，P22 后半缺少新的旋律触发；不能据此认定为正式尾声 |

整体是：**短引入—固定音型铺陈—旋律主体—短句变奏与和声变色—换调琶音段—带节奏的再现—循环。**

本曲没有前一工程那样明显的“全编制终章持续加密”。最大单 Pattern 触发数在 B 段 P4（258 次），而 D/E 的重要变化是声部角色和音区重组。触发数描述写谱密度，不代表实际响度或听感高潮。

## 3. 通道与声部分工

| 通道 | A 段 | B/C 段 | D/E 段 |
|---|---|---|---|
| Ch 0 | 1 `EBass3` 的 D# 反复；P1 行 34 起换 15 `bass` | 1 `EBass3`，根音—五度—八度型持续运动 | 改用 3 `f8d`，与 Ch 3 同节奏、高八度，转成前景琶音 |
| Ch 1 | 2 `f3f` 的 A# 长音 | B：3 `f8d` 主旋律；C：短旋律/和声提示 | 2 `f3f`，低位和声的上方五度 |
| Ch 2 | 2 `f3f` 的 D# 长音 | B：14 无名 Instrument，晚 9 行复制 Ch 1；C：改用 3，与 Ch 1 同步八度或和声音程 | 2 `f3f`，低位根音支点 |
| Ch 3 | 3 `f8d` 连续琶音 | 继续承担流动音型，C 段有密度变化 | 改用 5 `f1aa`，中高音核心琶音 |
| Ch 4 | 3 `f8d` 的延迟琶音 | 通常晚约 5 行呼应 Ch 3；部分乐句开头被重新截断/启动 | 5 `f1aa`，晚 2 行、低一个八度复制 Ch 3 |
| Ch 5 | 4 `f7d` 同音叠加 Ch 3 | B 同音叠加；C 从同音逐步降为低一、低二八度层 | 4 `f7d` 与 Ch 3 同音同时间 |
| Ch 6 | 4 `f7d` 同音叠加 Ch 4 | 随 Ch 4 构成延迟层，C 中也降低音区 | 4 `f7d` 与 Ch 4 同音同时间 |
| Ch 7 | 重音与逐渐进入的节奏事件 | 主要节奏通道，交替调用多个 Instrument | D 稀疏进入；E 以 6/11 每 12 行轮替 |

本曲的重要机制是**同音叠层与写在谱面上的延迟**。前半 Ch 3/5、Ch 4/6 的大量重合不是四条独立和声线；B 段 Ch 2 是旋律回声，D/E 又把它改作低音。这些角色需要随段落读取。

## 4. Bass 选择

### 1 `EBass3`：主要持续运动声部

P0 的 Ch 0 反复写 D#6，穿插 note-off，形成断续脉冲。P3–P14 则多为每三行一次的根音、五度与八度运动，例如 P3 开头：

`D#5 → D#5 → D#6 → A#5 → D#5 → A#5 → D#6 → A#5`

后续根音变化直接推动和声，而上方琶音经常保留原有材料。它是本曲前半最稳定的 Bass 功能声部。

“Bass”在这里首先是 Instrument 名称和编曲角色；记谱范围包含 D#6 等高音，接口又未给出样本调音、键盘映射，因此不能仅凭音符编号推断实际低频覆盖。

### 15 `bass`：引子后半的局部替换

P1 行 34 起，Ch 0 从 1 换成 15，先做上行/回落装饰，随后保持 D#—A# 的八度型运动；P2 继续使用 15。进入 P3 后回到 1。两个 Bass 命名的 Instrument 有清楚的结构分工，但不能从名称断言其原声/合成属性或真实音色差异。

### 2 `f3f`：后半真正的低位支点

P15 起，Ch 0 不再承担 Bass ostinato；Ch 1/2 的 2 `f3f` 改用 A#3–F4、F#3–C#4、G#3–D#4 等长五度，承担根音与和声底座。

因此，这首曲子的 Bass 设计不是“换调后继续使用同一个低音型”，而是**由密集 Bass 线转为低位持续五度，让连续运动交给琶音声部**。

## 5. 和弦与伴奏音色

主要配器组合是：

- A–C：3 `f8d` 的活动音型，叠加 4 `f7d`；A 另有 2 `f3f` 的长五度。
- D/E：5 `f1aa` 与 4 `f7d` 同音叠层，上方增加 3 `f8d` 的八度复制，下方恢复 2 `f3f` 的长五度。
- C 中，4 `f7d` 的音型逐步比 3 `f8d` 低一个、两个八度，增加纵向音区跨度。这是声部配置变化，不能简单写为“多加了一种低音音色”。

样本表出现 `Pulse 8.wav`（184 帧）、`SAMPLESPC98`、`extbrass`、`kick` 等名称，说明工程包含脉冲波、PC-98 标签与其他采样来源线索。然而，**当前接口没有 Instrument→Sample 的键盘映射**：Sample 4 名为 `Pulse 8.wav` 并不证明 Instrument 4 `f7d` 必定调用它；也不能把 `extbrass` 直接认定为主旋律音源。

本报告以实际 Instrument 编号和音符分工描述“主要音色”。合成波形、音色包络、失真、空间处理和最终质感留待人工试听确认。

## 6. 主旋律与重复关系

- **A：音型本身就是前景。** Ch 3–6 持续奏 D# 小调琶音；Ch 1/2 尚未成为旋律，而是长五度。
- **B：旋律从琶音上方进入。** Ch 1 的 3 `f8d` 音符较长、乐句有清楚起伏；Ch 2 的 14 把它完整推迟 9 行。P3/P6、P4/P7、P5/P8 的 Ch 0 与 Ch 3–6 音符相同，主旋律 Ch 1/2 则发生变化，是“相同伴奏、两轮旋律”的组织。
- **C：旋律改成短句提示。** P9/P10 的 Ch 1/2 是同步八度关系；P12/P13 变为同步的不同音程。P11/P14 没有新的 Ch 1/2 音符触发，但前一个 Pattern 的音会先延续，直到相应 note-off，不能直接当作从行 0 起完全静音。
- **D/E：前景与琶音合一。** Ch 0 比 Ch 3 高一个八度并同步；Ch 4 又在低八度晚 2 行进入。主要听觉轮廓预计来自同一线条在多个音区的铺开，具体前后景比例取决于音色与音量。
- **E 的有音高部分完整重复 D。** P15/P18、P16/P19、P17/P20 的 Ch 0–6 音符数量、行位置和音高逐一相同；两段差别主要在节奏事件、部分控制/音量设置与末尾跳转，而不是新的和弦或旋律。

## 7. 鼓组与节奏音源

只有 Ch 7/8 承担明确的固定 C-5 触发层，与前一工程的四条独立打击通道不同。Ch 7 在同一通道内切换多个 Instrument，不能按“每条通道对应一种鼓”的方式解读。

| Instrument | 主要出现位置 | 从数据能确认的角色 |
|---|---|---|
| 6 `86` | 引入及大多数节奏段 | 固定键节奏触发；精确鼓种未知 |
| 8 `p3` | A 后半、B/C、D 末尾 | 与 6 交替构成主要节奏型 |
| 11 `p6b` | 引入、少量填充、E | E 中与 6 轮替，构成稀疏而规律的脉冲 |
| 9 `p7` | P9–P11 | C 前半的附加节奏材料，未据名称判作底鼓 |
| 10 `p8` | A 与 D 的部分重音 | 常在 48 行边界附近出现 |
| 12 `Drum+cymb` | P9–P11 | 名称提示鼓/镲组合，具体组成未试听 |
| 13 `f20d` | C 前半 Ch 7、D 的 Ch 8 | 固定 C-5 的节奏/重音事件；即使名称类似有音高乐器，也不能据此强行纳入和弦 |
| 16 `p5` | A 的 Ch 8 | 与开头若干长五度重音对齐 |
| 7 `Crash-Cymbal-1` | 本次未发现音符触发 | 表中存在，不等于实际用于本曲 |

引入 P23 的 Ch 7/8 在行 0、3、6 各触发一次，并有逐步增加的显式音量值，形成短促的进入提示。D 的 P15 完全没有新的打击触发，P16/P17 才逐步补入；E 的 Ch 7 每 12 行轮替 6/11，共 32 次触发，对应八个推定小节中的四拍脉冲。

C 的 P9–P11 调用了更多种节奏 Instrument，P12–P14 则主要回到 6/8，变化体现在音源组合而非单纯增加通道数。

## 8. A–E 分段常用和弦与主要音色

### 8.1 判读口径与总览

和弦从持续支点、根音型、三音及旋律落点判断，按乐句时间窗合并分解音；不把整段所有经过音都当作同时发声的复杂和弦。Ch 7/8 排除，八度/同音复制不重复算作新的和声音级。

本曲前半沿用 D#、F# 等升号拼写：Tracker 的 F 在 D# 小调语境中读为 E#，D 读为 C𝄪，G 读为 F𝄪。后半为方便看清 A# 小调的 i–VI–VII 关系，保留 `A#m、F#maj7、G#`，同时注明 C 在 G# 大和弦中相当于 B#。

`m` 表示小三和弦，`maj7` 为大七和弦，`7` 为属七和弦。斜线表示上方和声材料叠加某个功能低音，不保证每一瞬间的最低记谱音都等于斜线后的音；尤其 C 的低八度强化层有时会低于 Ch 0。

| 段落 | 常用和声缩减 | 主要音色 |
|---|---|---|
| A：P0–P2 | D#m 持续；E#、G# 作为九度/四度活动音 | 1→15 的 Bass；2 `f3f` 长五度；3 `f8d` + 4 `f7d` 琶音 |
| B：P3–P8 | `D#m → D#m7/C# → Bmaj7 → A#属功能`，反复四轮 | 1 Bass；3 主旋律和琶音；14 延迟旋律；4 复制层 |
| C：P9–P14 | `Bmaj7 → C#扩展/悬挂和声 → D#m`；后段上层三音升高，转为 D# 大和弦色彩 | 1 Bass；3 短旋律与活动层；4 逐步降八度 |
| D：P15–P17 | `A#m → F#maj7 → G#扩展和声`；A#m 上层在低音换根时仍保留 | 2 低位五度；3 上方琶音；5 + 4 中低音叠层 |
| E：P18–P20 | 完整重复 D 的和声与有音高旋律 | 同 D；6/11 的规律节奏成为主要差别 |

### 8.2 A：D# 小调固定音型（P0–P2）

**常用和弦是 D#m，而不是一串每小节更换的三和弦。**

P0 行 0 的 Ch 1/2 写 A#4、D#4；Ch 3 在行 0、3、6 依次写 D#5、F#5、A#5，明确形成 D#–F#–A#。随后 E#（显示 F）与 G# 被插入上行/回旋音型，为九度与四度色彩。Ch 0 的 D# 反复和长五度都没有随这些短音改变根音，故不应把每个琶音音符都命名为新和弦。

该 48 行琶音从 P0 行 0、48、96 启动，跨入 P1 后继续，在 P1 行 16、64、112 再次启动，到 P2 行 32、80 完成后续轮次。三 Pattern 共八轮。

**主要音色与变化：** 2 `f3f` 提供稳定五度；3/4 分别以 `f8d`、`f7d` 同音叠加。Ch 4/6 通常比 Ch 3/5 晚 5 行，但部分跨句位置有重新截断，不把整段描述为毫无例外的固定 delay。Ch 0 在 P1 行 34 换 15 `bass` 并增加旋律性填充，为 B 的密集 Bass 奠定运动感。

### 8.3 B：下降低音与旋律呼应（P3–P8）

每 192 行构成一轮四格，每格 48 行；P3–P8 共 768 行，即四轮。第一轮跨越 P3 与 P4：

| 第一轮位置 | Bass 支点与关键音 | 和弦判读 |
|---|---|---|
| P3 行 0–47 | Ch 0：D#、A#；琶音：D#、F#、A# | D#m，含 E#/G# 装饰 |
| P3 行 48–95 | Ch 0：C#、G#；上方仍为 D#、F#、A# | D#m7/C#，比直接写 C# 大三和弦更能反映上层保持不变 |
| P3 行 96–127 → P4 行 0–15 | Ch 0：B、F#；上层含 D#、F#、A# | Bmaj7；G#、E# 等为活动色彩 |
| P4 行 16–63 | Ch 0：A#、E#（显示 F）；Ch 1 行 16 出现 C𝄪（显示 D），上层也出现 G# | A# 大三和弦/属七骨架，但同时保留 D#、F#，带挂留四度与降十三度色彩 |

A# 的属功能也见于 P5 行 104、P7 行 16、P8 行 80 等旋律中的 C𝄪。这里不能只凭上层有 D#、F# 就判作 A#m：Bass 的 E# 与旋律的升导音支持回到 D#m 的属功能。但它也不是整格毫无装饰的纯 A#7，上层固定音型始终参与。

四轮低音框架起点分别为 P3 行 0、P4 行 64、P6 行 0、P7 行 64。这解释了为何 Pattern 中部常出现和声“重新开始”。

**主要音色：** Ch 0 固定使用 1 `EBass3`；Ch 1 的 3 `f8d` 开始承担独立主旋律，Ch 2 用无名 Instrument 14 晚 9 行复制，共核对到 44 个一一对应的旋律触发。Ch 3/4 的 3 与 Ch 5/6 的 4 构成两组同音琶音层。后组三个 Pattern 并未换和弦或伴奏骨架，主要变化在主旋律。

### 8.4 C：VI–VII–i 型短句与三音变色（P9–P14）

前半的功能轮廓是 `B → C# → D#` 低音推进，结合上方小调材料，常缩减为：

**Bmaj7 → C# 的扩展/悬挂和声 → D#m。**

它比 B 的四格下降低音更短促。以 P9 为例：

| 位置 | 证据与解释 |
|---|---|
| 行 0–23 | Bass 为 B/F#，活动层含 D#、A#，形成 Bmaj7 骨架；其他经过音不另立和弦 |
| 行 24–41 | Bass 为 C#/G#，旋律行 24 的 F 即 E#，明确 C# 大三音；上层 D#、A#、F# 形成九度、六度、挂留色彩 |
| 行 42 起 | Ch 0 提前触发 D#，行 48 起进入完整 D# 根音型；上层 F#、A# 回到 D#m |
| 行 96 起 | 下一轮在 Pattern 内提前开始；第二格跨 P9/P10 边界 |

以 96 行为一个低音短句，P9–P14 总共八轮。部分 C# 格没有明显 E#，只有持续的 D#–F#–A# 加 C# 低音，宜记为 D#m7/C# 或 C# 悬挂织体，而不是逐次都强行写 C# 大三和弦。

**后半有明确的三音升高。** P13 行 106 起，Ch 3/5 把原来的 F# 改为 G（和声拼写 F𝄪）；延迟层在行 111 跟入。P14 多处持续使用 D#–F𝄪–A#，上层由 D# 小三和弦变为 D# 大三和弦。

不过 Bass 仍走 B–C#–D#，所以这不是“全曲从此整体升半音”，也不是每一格都变成 D# 大和弦：例如 P14 的 B 低音段仍会奏出 F#，与上层 F𝄪形成更复杂的叠置。到 P14 行 80 后 D# 低音稳定时，大三和弦的归属才最清楚。它可视为进入 D 段前的和声变色；直接判为 A# 小调的正格属和弦则不合适，因为 A# 小调的属和弦应以 E# 为根音。

**主要音色：** 1 `EBass3` 保持；Ch 1/2 改为 3 `f8d` 的同步短句，P9/P10 主要八度强化，P12/P13 改写为不同音程。Ch 3/4 仍使用 3，但每三行触发的连续运动与每六行一次的疏音型交替。4 `f7d` 复制层逐步下降一、二八度，形成更宽的音区，而非换用另一种 Bass。

**待核对的一格：** P14 行 79，Ch 4 是 G-6，Ch 6 是 F#4；通常两者应按既有写法相差两个八度，这一格却相差 25 个半音。两通道显式音量分别为 6、25，实际听感不能由音高差单独决定。可能是刻意保留小三音，也可能是变奏时未同步修改；这里只记录差异，不判定或修正。

### 8.5 D：A# 小调琶音与低位五度（P15–P17）

这里是全曲最明显的配器分界。Ch 0 不再用 Bass，而改成高音琶音；Ch 1/2 从旋律角色退回低位五度；Ch 3/4 换成 5 `f1aa`，并把延迟从约 5 行改成精确 2 行。

主要上层三音是 **A#–C#–E#**（Tracker 显示 A#–C#–F），因此更接近 A# 小调中心。它与前半 D# 小调有关联，但不是全体音符统一移调的复制。

| 低位支点区间 | Ch 2 / Ch 1 | 上层材料与和声缩减 |
|---|---|---|
| P15 行 0–95 | A#3 / E#4（显示 F4） | A#m；第一个 48 行单位反复 E#–C#–A#，第二个单位加入 D#、B#（显示 C）、G# 等旋律音 |
| P15 行 96 → P16 行 15 | F#3 / C#4 | 上方仍有 A#、C#、E#，合成 F#maj7 |
| P16 行 16–63 | G#3 / D#4 | 初段保留 A#m 上层，可写 A#m7/G#；行 31 等出现 B#（显示 C），又明确 G# 大三和弦的色彩 |
| P16 行 64 → P17 行 31 | A#3 / E#4 | 回到 A#m，含活动旋律 |
| P17 行 32–79 | F#3 / C#4 | F#maj7 |
| P17 行 80–127 | G#3 / D#4 | A#m7/G# 与 G# 扩展和声交织，准备后续重复 |

按八个 48 行单位概括，是：

`A#m | A#m（旋律展开） | F#maj7 | G#扩展 | A#m | A#m（旋律展开） | F#maj7 | G#扩展`

G# 段不是从头到尾只奏 G#–B#–D#：持续的 A#、C#、E# 给出九度、挂四、十三度色彩；用单一三和弦符号只能表达根音功能，不能代替实际声部。

**主要音色：** 2 `f3f` 的长五度明确低位支点；Ch 0 的 3 `f8d` 比 Ch 3 高八度同步；Ch 3 的 5 `f1aa` 与 Ch 5 的 4 `f7d` 同音叠加；Ch 4/6 则低一个八度、晚 2 行。P15 没有新打击触发，P16/P17 才逐渐加入重音与短填充，形成明显的空间变化。

### 8.6 E：D 的再现与循环连接（P18–P20）

E 的和弦、调性、低音支点和有音高旋律均与 D 相同：

- P18 对应 P15。
- P19 对应 P16。
- P20 对应 P17。

这三对 Pattern 的 Ch 0–6 音符位置和音高完全匹配，Instrument 分工也一致。因此本段**没有额外转调，也不是更高音区的终章版本**。

区别主要在 Ch 7：6 `86` 与 11 `p6b` 以每 12 行一次的网格轮替，而 D 前半更为稀疏。八个推定小节合计 32 次节奏触发，增加稳定的拍点。P20 行 127 的 B00 把播放带回 P23，P23 行 0 又切断 Ch 0–6，并重新触发短打击提示，形成可辨识的循环接缝。

## 9. 音源选择评价与人工试听重点

从写谱设计看，本曲有三个鲜明特点：

1. **少量 Instrument 的角色复用。** 3 `f8d` 先作琶音、再作独立主旋律、最后又成为高八度琶音；2 `f3f` 在前后段都提供长五度，却占据不同音区。
2. **通过复制方式改变结构。** 同音叠层、晚 5 行的琶音呼应、晚 9 行的旋律呼应，以及后半晚 2 行的低八度线条，共同建立声场与密度差异。
3. **和声依赖低音与上层材料的组合。** D#m 音型叠下降低音、A#m 音型叠 F#/G# 支点，比简单的逐格三和弦替换更能解释本曲。

建议人工试听时优先确认：

- Ch 3–6 同音叠层是否让旋律与琶音难以区分，尤其 B 段 3 同时用于前景与背景。
- C 段 4 的低八度、低二八度版本与 Ch 0 Bass 是否出现掩蔽，以及 P14 行 79 的半音偏差是否符合意图。
- 14 无名 Instrument 与 3 的实际音色差异；9 行复制究竟听成回声、对答还是节奏干扰。
- P14 到 P15 从 D# 大和弦色彩转到 A# 小调材料的连接，以及 P20→P23→P0 的切音循环是否自然。
- P21/P22 是否有作者希望纳入播放的用途；现状仅如实记录，未改写 B00 或曲序。
